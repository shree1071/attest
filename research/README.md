# Research & Architectural Experiments

This directory stores technical documentation, prototype evaluations, and architectural proposals for the Attest platform.

Per industry solo developer engineering standards (Software Engineering Stack Exchange & GitHub Flow guidelines), all R&D and proof-of-concept notes are maintained in `/research` on the primary branches (`staging` / `main`) rather than in detached long-lived branches to eliminate branch drift and painful merge conflicts.

## Documents

- [Target Edge Architecture](./TARGET_ARCHITECTURE.md) — Specification for Next.js on Cloudflare Workers, Hyperdrive, Neon Postgres, and Turnstile.
- [Branching Strategy](./BRANCHING.md) — 2-Branch Client-Approval workflow guide.
